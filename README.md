# Aula de Desenvolvimento Web I 2026/2

Este repositório contém uma página estática em HTML para a disciplina de Desenvolvimento Web I.

## Descrição

O projeto apresenta um exemplo simples de estrutura HTML com uma seção de apresentação pessoal.

## Arquivos

- `index.html` — página principal do projeto.

## Como visualizar

1. Abra o arquivo `index.html` diretamente no navegador, ou
2. Execute um servidor local na raiz do projeto:

```bash
python -m http.server 8000
```

Depois, acesse `http://localhost:8000` no navegador.
